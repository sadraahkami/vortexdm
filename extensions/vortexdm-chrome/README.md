# VortexDM Browser Integration (Chrome / Edge / Brave / Opera)

Official browser extension for **VortexDM** (Manifest V3).

## Features
- 🚀 **Context Menu Integration:** Right-click any link or media file and select **"Download with VortexDM"**.
- ⚡ **Auto-Capture Downloads:** Optionally intercept and capture all standard browser downloads into VortexDM.
- 📋 **One-Click Popup:** Quick clipboard URL detection and instant multi-threaded acceleration.
- 🔒 **Privacy-First:** 100% local communication with your VortexDM desktop instance (`http://127.0.0.1:8080`).

## Installation Guide (Developer Mode)

1. Open your browser's extension manager:
   - **Google Chrome:** `chrome://extensions`
   - **Microsoft Edge:** `edge://extensions`
   - **Brave Browser:** `brave://extensions`
2. Enable **"Developer mode"** (toggle in top-right corner).
3. Click **"Load unpacked"** (بارگذاری بسته باز نشده).
4. Select this directory: `vortexdm/extensions/vortexdm-chrome`.
5. The VortexDM icon will appear in your extension toolbar!
